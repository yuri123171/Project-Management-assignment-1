
# Week 1 - Project Management: ShopSmart Retail Analytics & AI Implementation Project

**Mission PM01** | Client: ShopSmart Retail Group | Delivery partner: AnalystLab Africa Consulting
**Project Manager:** Yuri | **Version:** 1.0 (draft for sponsor approval) | **Date:** 2 November 2026

## Project in one paragraph
ShopSmart Retail Group (25 stores, 10 Nigerian states) has data in separate systems and no integrated analytics or AI. This package initiates and plans a 12-week project (9 Nov 2026 to 29 Jan 2027) that delivers four Power BI dashboards, a cleaned dataset and feature pipeline, machine learning models and a Generative AI Retail Copilot. Work is delivered in a development environment; production deployment is out of scope.

## Findings from the ShopSmart datasets that shaped the plan
- Only about 33% of the 50,000 orders are Completed (about 34% Cancelled, 33% Pending).
- About two thirds of the 2,500 returns relate to Pending or Cancelled orders; 58 orders have several return records.
- 49 duplicate customer emails and 4 duplicate phone numbers; names conflict with recorded gender in some records.
- Each order has a single product; inventory has one record per product; all data is from 2025.
